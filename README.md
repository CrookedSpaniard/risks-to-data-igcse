# Risks to data and personal information — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 3 Operating online, chapter 6: Risks to data and personal information** (book pages 96–108). Only this chapter is covered.

Each section is explained step by step with interactive simulations, followed by the book's **activities** (where the book has them) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes, including the book's chapter questions).

**Part A · Risks to data and information** (pages 96–99)

1. Unauthorised access — Figure 6.1 data online, login software trying thousands of passwords, botnets spreading malware → ✓ Check
2. Deliberate damage by malware — messages, sounds, deleted files, reprogrammed hardware; ransomware and the pressure to pay → Activity (Stuxnet) → ✓ Check
3. Accidental deletion — a key pressed by accident, formatting the wrong drive, a power cut → ✓ Check
4. Phishing — sort an inbox, links and webforms, spear phishing, SMS phishing (smishing) → ✓ Check
5. Pharming — altered domain name servers, malware redirects, look-alike URLs → ✓ Check
6. Test Part A

**Part B · Keeping data secure and paying online** (pages 99–108)

7. Firewalls and encryption — rules for addresses and ports, a key that scrambles data → ✓ Check
8. Passwords, PINs and biometrics — strong-password checker, masking, remembered passwords on stand-alone vs network operating systems → Activity → ✓ Check
9. CAPTCHA tests and security questions — distorted characters vs a bot, image grid, audio, reCAPTCHA digitising a book → Activities → ✓ Check
10. Anti-malware and file permissions — virus definitions and quarantine, updates, adware, a keylogger, read only / read and write → Activity (Staying alert) → ✓ Check
11. Secure websites, attachments and links — HTTP vs HTTPS (SSL/TLS, padlock), the warning signs in an email, hovering over links → ✓ Check
12. Backup procedures — disasters and online storage, full / differential / incremental, good ideas → Activities (Data security, RAID) → ✓ Check
13. Online payment systems — mobile payments (Figure 6.16), third-party processors, bank cards and CSC, authentication, contactless NFC and foil, HTTPS → Activity (fact sheet) → ✓ Check
14. Test Part B · Key terms (searchable)

**Progress that students can share and resume** (same system as the other lessons)

- Everything is saved automatically in the student's browser (`localStorage`, key `rd-progress-v1`).
- **My progress** shows the percentage completed, with **Copy my progress** / **Download .txt** for the teacher, and a **progress code** (`RD1Z.…`) to carry on with another device.
- Nothing is sent to a server. Students are told never to type real passwords or card numbers.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#phishing` or `#check-backup`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step. All simulations, emails, websites, banks and people are original and made up, except examples taken from the book.
